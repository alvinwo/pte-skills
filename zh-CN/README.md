# PTE Skills 中文版

[English](../README.md) | 简体中文

一套可以自己读、也可以交给 AI 带练的 **PTE Academic 备考指南**。先确定目标和短板，再安排今天练什么、怎么练、错了怎么改。

中文版保留 RA、RS、WFD 等常用缩写。方法用中文讲，题目、示范答案和考试作答用英文。适用于 PTE Academic；不要直接套用到 PTE Core 或 PTE Home。

## 不懂代码，也能开始

**自己学：** 从[入门](shared/start-here.md)开始，选[每天的时间表](shared/study-plan.md)，再打开需要的题型。

**让 AI 带练：** 打开[AI 带练说明](shared/coaching-guide.md)、[学习计划](shared/study-plan.md)和一个题型文件，把内容复制进你使用的 AI 对话，或下载后上传这些文件。需要其他参考页时再补充上传；贴一个文件不代表 AI 自动读到了它的链接。

可以先复制这段话：

> 请按我提供的 PTE Skills 指南带练。我考 PTE Academic，每天有45分钟，还有3周，写作最弱。用中文解释，英文出题和示范。已经告诉你的信息不用重复问，缺少且会影响计划的信息再问。不知道的成绩先不要猜，先给临时计划。每次一题，等我作答再纠错，最后给一个重练任务。不要把练习反馈当成官方PTE分数。

无需 npm，也无需安装插件。`.md` 是普通文本文件，直接阅读即可。这里的文件是便于复制和读取的 Markdown 指南；把整个仓库放进某个工具，不代表已安装原生插件。语音和图片功能取决于你使用的 AI 工具，本项目本身不播放音频、不提供官方评分。

## 全部22种题型，21份指南

先看[题型全览](shared/task-map.md)，再读[整体备考路线](shared/study-roadmap.md)。两类阅读填空合用一份指南；以下保留最初九个核心入口，其余题型都能从全览进入。

### 最初九个核心入口

| 缩写 | 题型 | 适合解决的问题 |
| --- | --- | --- |
| RA | [朗读](skills/pte-read-aloud.md) | 读得急、词尾不清、节奏不稳 |
| RS | [复述句子](skills/pte-repeat-sentence.md) | 听完记不住、漏意群 |
| DI | [描述图片](skills/pte-describe-image.md) | 看图不知道说什么、只背模板 |
| RL | [复述讲座](skills/pte-retell-lecture.md) | 主旨和支持信息记不住 |
| SGD | [总结小组讨论](skills/pte-summarize-group-discussion.md) | 混淆说话人、遗漏观点关系 |
| RTS | [情境回应](skills/pte-respond-to-a-situation.md) | 没回应请求、语气不合适 |
| WFD | [听写句子](skills/pte-write-from-dictation.md) | 漏小词、拼写和词尾错误 |
| Reading Blanks | [阅读填空](skills/pte-reading-blanks.md) | 语法、搭配、上下文判断不稳 |
| SWT | [总结书面文本](skills/pte-summarize-written-text.md) | 主旨不全、单句结构失控 |

已补齐WE（作文）、ASQ、RO、阅读单选/多选、SST、听力填空、听力单选/多选、HCS、SMW、HIW的独立指南。完整入口见[题型全览](shared/task-map.md)。这是全部题型的基础指南，不等于完整题库或官方模考。
