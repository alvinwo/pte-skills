# PTE WE | Write Essay

## Purpose

- Develop a reasoned answer to the essay prompt.

## When to use

- When essay relevance, development, or sentence control limits Writing.

## Success looks like

- A clear position where requested, supported reasons, coherent paragraphs, and accurate language.

## Common mistakes

- Answering a different question; listing ideas without explanation; reproducing an unrelated essay.

## Practice method

1. Analyse what the prompt asks.
2. Plan a position and two supporting points.
3. Write paragraphs that explain each point with a relevant example.
4. Check the argument, language, and word count.

## Special notes

- PTE Academic: 200–300 words, 20 minutes. Suggested practice split: 3 minutes plan, 14 write, 3 check.
- Original planning drill: Should universities require group projects? Write one benefit, one limitation, and your position before drafting.

## Daily target

- Use a full 20-minute attempt when WE is a priority; schedule feedback separately. Short paragraph drills supplement it.
