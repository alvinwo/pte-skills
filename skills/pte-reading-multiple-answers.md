# PTE Reading | Multiple Choice, Multiple Answers

## Purpose

- Identify all supported answers while evaluating each option independently.

## When to use

- When over-selection or missed qualifications causes repeated errors.

## Success looks like

- Each chosen option has evidence; unsupported options are left out.

## Common mistakes

- Selecting everything vaguely relevant; assuming a fixed number of correct options.

## Practice method

1. Read the question and passage.
2. Classify each option as supported, contradicted, or not established.
3. Select supported answers.
4. Review the exact evidence for both selected and rejected options.

## Special notes

- Incorrect selections lose points; do not select extra options merely because they sound plausible. In a drill, underline the phrase that supports each selection.

## Daily target

- A short targeted block when needed, with more time explaining choices than guessing again.
