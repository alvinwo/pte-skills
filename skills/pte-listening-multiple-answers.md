# PTE Listening | Multiple Choice, Multiple Answers

## Purpose

- Select the options supported by the recording.

## When to use

- When extra choices erase otherwise correct work or details are confused.

## Success looks like

- Separate evidence for every selected option.

## Common mistakes

- Guessing extra options; missing contrasts such as although or instead.

## Practice method

1. Preview the question.
2. Note relevant ideas rather than every word.
3. Evaluate each option against the recording.
4. Review selections using the transcript only after answering.

## Special notes

- Wrong selections lose points. Select supported options, not every option that includes a word from the recording.

## Daily target

- Short targeted practice; log whether each error was a missed detail or an unsupported extra choice.
