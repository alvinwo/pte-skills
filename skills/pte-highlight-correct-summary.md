# PTE HCS | Highlight Correct Summary

## Purpose

- Select the summary that represents the recording as a whole.

## When to use

- When one correct detail distracts from a wrong main message.

## Success looks like

- The main claim and its important relationships are preserved.

## Common mistakes

- Choosing an option with familiar words but a reversed conclusion or invented cause.

## Practice method

1. Note the topic and central claim while listening.
2. Summarize that claim mentally before comparing options.
3. Check each option’s scope and supporting relationships.
4. Reject distortions and select one summary.

## Special notes

- This is choosing a summary, not writing SST. During review, identify exactly which part makes each distractor wrong.

## Daily target

- A short comprehension block; review meaning, not just vocabulary.
