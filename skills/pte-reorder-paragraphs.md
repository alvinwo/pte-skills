# PTE RO | Reorder Paragraph

## Purpose

- Restore the logical order of text blocks.

## When to use

- When reference words, sequence, or argument development cause Reading errors.

## Success looks like

- A coherent sequence with justified links between adjacent blocks.

## Common mistakes

- Ordering by one keyword alone; selecting a dependent sentence as the opening.

## Practice method

1. Find a plausible standalone introduction.
2. Match references such as this approach to their antecedents.
3. Build strongly supported adjacent pairs.
4. Check the full sequence for time and logical consistency.

## Special notes

- Original drill: A introduces a policy; B begins “This policy”; C describes its later results. Explain why A precedes B and where C belongs. Partial credit rewards correct adjacent pairs; avoid treating the task as all-or-nothing.

## Daily target

- Use a timed reading block; review why each pair works, not just the answer order.
