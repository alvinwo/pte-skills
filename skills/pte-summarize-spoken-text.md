# PTE SST | Summarize Spoken Text

## Purpose

- Write a summary of a spoken passage.

## When to use

- When notes capture isolated words but lose the main message or supporting information.

## Success looks like

- Accurate main idea and relevant support, expressed clearly in the required form.

## Common mistakes

- Using SWT’s single-sentence constraint; adding facts not heard; spending all available time drafting.

## Practice method

1. Listen and note the topic, main claim, and supporting relationships.
2. Write a compact summary from notes.
3. Check source fidelity, grammar, spelling, and word count.
4. After the attempt, compare with the transcript and retry one weak part.

## Special notes

- PTE Academic: 50–70 words; 10 minutes includes listening and writing. It need not be a single sentence. During training, distinguish unaided first attempt from transcript-assisted review.

## Daily target

- One full attempt when prioritized; allow extra review time outside the task timer.
