# From orientation to exam preparation

Keep the useful sequence of learning the task landscape before planning practice. The user used [Sun Peter part 1](https://sunpeteraustralia.com/pte/) and [part 2](https://sunpeteraustralia.com/pte-2/) for orientation. They are historical experience reports; current rules come from [Pearson](sources.md).

## 1. Orient

Use the [22-type map](task-map.md). Attempt each type at least once and identify its input and required output. Distinguish SWT/SST, reading/listening multiple answers, and both reading-blank variants. Become familiar with the interface and microphone before chasing scores.

## 2. Diagnose

Record target scores, available time, and recent results. Classify errors from representative attempts: decoding, recall, content, structure, spelling/grammar, delivery, or time management. Choose two primary tasks instead of copying another candidate’s priority order.

## 3. Learn and accumulate

Use the [daily plan](study-plan.md): attempt, compare, correct, retry. Add the next task gradually while retaining earlier learning. Use the contributor’s RS/WFD routine: familiarity without compulsory rote learning for RS; exact memorization where feasible for WFD.

For RL, SST, and SGD, try three learning rounds: independent listening/output; transcript-assisted comprehension and replay; then another summary without the transcript. Keep one-play simulations separate, and never log an answer-assisted retry as first-attempt performance.

## 4. Check transfer and timing

Review both corrected familiar items and unfamiliar items weekly. Turn automatic spelling/grammar correction off during practice attempts, then use feedback afterwards and log what you missed independently. If the same weakness persists, change the practice task rather than only increasing volume.

## 5. Rehearse the full process

Reserve enough separate time for a complete practice test. Rehearse section pacing, the later listening tasks, and microphone operation. Check official booking, ID, and test-centre instructions. Judge readiness from recent evidence and current requirements.

Phase length depends on starting level, deadline, and available time. The blog author’s two-month schedule is an individual history, not a universal improvement timeline.
