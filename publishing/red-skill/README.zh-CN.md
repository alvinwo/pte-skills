1. 在电脑端打开[小红书创作服务平台](https://creator.xiaohongshu.com/)，登录后进入Red Skill。
2. 如有“选择zip文件”，上传`pte-coach-zh.zip`；如要求文件夹，上传解压出的`pte-coach-zh`文件夹。
3. 检查平台解析结果：技能名、简介、文件清单是否完整。参考页位于`references/`，入口名为大写`SKILL.md`。
4. 填写信息、阅读平台规范后提交审核。不要仅上传ZIP内的主入口，它依赖参考页；需要单文件时使用上面的自包含备用版。
5. 审核通过后，在发布笔记的“添加组件 → Red Skill”选择该技能。还没审核或发布时，不把它描述为已上线。

## 安装后试一句

> 我考PTE Academic，还有3周，每天45分钟，RS听完容易漏后半句，WFD经常漏冠词。请用中文解释、英文练习，先给今天的安排，再一次一题带我练；等我回答后再展示原文和纠错。

检查：时间是否合计45分钟；听力首答前是否隐藏答案；是否区分“RS听熟不死背”和“WFD尽量背会并准确默写”；没有录音时是否避免虚构发音分数。

## 维护与重建

运行仓库根目录的`python scripts/build_red_skill.py`。修改学习内容时，先改`zh-CN/`下的原文件，再重建；修改入口时改`publishing/red-skill/pte-coach-zh/SKILL.md`。`references/`、`LICENSE.txt`、ZIP与单文件版均为构建产物，不单独编辑。

构建会保留包内相对链接，把未打包的拓展阅读转为GitHub链接；单文件版将本地依赖改为内嵌章节。外部阅读链接不是开始练习的必需依赖。许可证沿用仓库MIT，未复制YouTube视频、Reddit帖子全文、第三方文章或商业题库。

本次完成了格式、依赖、ZIP完整性与内容覆盖检查；未在小红书账号中上传、审核或运行。
